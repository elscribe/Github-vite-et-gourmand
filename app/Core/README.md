# Dossier Core

Le dossier `Core/` contient les classes techniques partagees par toute
l'application : routeur, controleur de base, modele de base, aide de connexion
PDO, chargement d'environnement, session, gestion d'erreurs, helpers de
securite, helpers d'entree et de reponse.

Ces classes soutiennent la structure MVC mais ne contiennent pas de regles
metier.
