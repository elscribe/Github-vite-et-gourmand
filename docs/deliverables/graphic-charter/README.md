# Charte graphique

Ce dossier reference la charte graphique finale du projet Vite & Gourmand.

## Export principal

La charte graphique PDF est conservee dans :

```text
Maquettes/export pdf/Charte graphique complete - Vite & Gourmand - ECF.pdf
```

Selon le systeme de fichiers, le nom du fichier peut contenir un accent dans
`complete`.

## Contenu attendu

La charte graphique doit presenter :

- logo ;
- palette de couleurs ;
- typographies ;
- boutons et CTA ;
- iconographie ;
- composants principaux ;
- exemples d'utilisation dans les maquettes.

## Role dans le rendu

La charte graphique permet de justifier la coherence visuelle du site et
l'adaptation au contexte de Vite & Gourmand : traiteur familial, offre
gastronomique, espace public chaleureux et back-office lisible.
