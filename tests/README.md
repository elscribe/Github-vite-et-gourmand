# Dossier Tests

Ce dossier est reserve aux futurs tests automatises.

Aucun framework de test n'est installe pour l'instant. Le controle minimal
disponible est `composer check`, qui valide Composer et la syntaxe PHP.

Quand les parcours seront stabilises, ajouter en priorite des tests sur
l'authentification, les droits d'acces, les commandes, les calculs de prix et
les transitions de statut.
